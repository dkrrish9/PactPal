# Subsystem: Web App & Bryntum Gantt UI (`frontend`)
**Stream Branch**: `feature/frontend`  
**Stream Lead / Owner**: 1 - Frontend (FE)

## Overview
User-facing portal for Buyers, Sellers, and Platform Admins. Integrates sponsor tool **Bryntum Gantt & Scheduler** to visualize contract feature tasks, deadlines, and the 29-day PayPal hold countdown.

## Key Views & Features
- **Contract Creation Wizard**: Form-based contract inputs enforcing measurable acceptance tests and priced weights.
- **Contract Dashboard**: Real-time status badge (10 states), escrow hold indicator, and deadline countdown.
- **Bryntum Gantt Chart**: Dynamic timeline displaying checklist items as Gantt tasks, with status colors (pending, passed, failed).
- **Negotiation Chat**: Interactive chat room for mid-project change requests and mini-agreement confirmations.
- **Verification Activity Feed**: Real-time log showing Stage A-F progress in Render containers.
- **Proof-of-Work Receipt View**: Displays the SHA-256 fingerprint, breakdown of verified features, test coverage stats, and PayPal reference link.
